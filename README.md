# fromturbo for Mac

The built fromturbo editor, packaged as a [BananaPeel](https://www.npmjs.com/package/@blockblock2/bananapeel) app. Get it as a DMG:

```bash
bananapeel dmg blockblock2/fromturbo@mac
```

That downloads it, virus-scans it, and builds `fromturbo-1.0.0.dmg` on your own Mac. Drag fromturbo onto Applications.

Or install it with `bananapeel install blockblock2/fromturbo@mac`.

The DMG version has one thing nothing else does: **🍌 Upload a mod** in the Mods menu.

Source code: the `main` branch of [blockblock2/fromturbo](https://github.com/blockblock2/fromturbo). Licensed GPL-3.0.
