Making fromturbo mods and extensions

A fast Scratch editor with a mod API anyone can use. Open the editor →

Mods Extensions Share it

Your first mod in 30 seconds

A mod is one JavaScript file. It calls fromturbo.mods.register and gets the whole API passed in.

fromturbo.mods.register({
    id: 'hello',
    name: 'Hello',
    run (api) {
        return api.ui.addMenuButton('Hello', () => api.ui.toast('Hi from my mod!'));
    }
});

Host the file anywhere (GitHub Pages, pages.dev, a gist's raw link), then in the editor open Mods, paste the URL and press Install. It loads every time after that.

To hand a mod to someone, link them to fromturbo.pages.dev/editor.html?mod=YOUR_URL. They'll be asked before it runs.

See the example mod

Try it right now from the browser console on the editor page: paste the snippet above and a button appears.

The API

Project

api.project.getJSON()The project as JSON (no asset files).
await api.project.getSb3()The whole project as an .sb3 Blob.
await api.project.load(data, title?)Open a project from an ArrayBuffer, Blob or project JSON.
api.project.getTitle() / setTitle(t)The project title.
api.project.editingTarget()The selected sprite (or stage).
await api.project.addBlocksXML(xml)Add scripts to the selected sprite from Scratch Blocks XML. Rejects unknown block types.

Editor UI

api.ui.addMenuButton(label, onClick)A button in the top menu bar. Returns a function that removes it.
api.ui.openPanel({id, title, render(body, panel)})A floating, draggable panel. panel.close() closes it.
api.ui.toast(message)A short pop-up message.
api.ui.h(tag, props, ...children)Tiny element builder. Use classes ft-btn, ft-quiet, ft-row, ft-muted, ft-item to match the built-in mods.
api.ui.activateTab(0|1|2)Switch to Code, Costumes or Sounds.

Events — api.on(name, fn) returns an unsubscribe function

projectChangedAnything in the project changed.
projectLoadedA project was opened through the API.
targetsUpdateSprites changed or a different sprite was selected.
workspaceUpdateThe code area was redrawn.
greenFlag / stopThe project started or stopped.
blocksAddedScripts were added with addBlocksXML.
modRegistered / modStartedAnother mod appeared or started.

Mods can also make their own events with api.emit(name, ...args) so mods can talk to each other.

Storage

Your run(api, {storage}) gets storage.get(key, fallback) and storage.set(key, value), saved per mod in the browser.

The raw stuff

api.vmThe Scratch VM (runtime, targets, everything).
api.blocks / api.workspaceScratchBlocks (Blockly) and the code area, once the Code tab has loaded.
api.reduxThe editor's Redux store.

Your first extension in 30 seconds

An extension adds new blocks to the block palette. A mod changes the editor; an extension changes what projects can do. An extension is one JavaScript file in the standard Scratch custom extension format, so it also works in TurboWarp.

(function (Scratch) {
    'use strict';
    class HelloBlocks {
        getInfo () {
            return {
                id: 'helloblocks',
                name: 'Hello Blocks',
                blocks: [{
                    opcode: 'hello',
                    blockType: Scratch.BlockType.REPORTER,
                    text: 'hello [NAME]',
                    arguments: {NAME: {type: Scratch.ArgumentType.STRING, defaultValue: 'world'}}
                }]
            };
        }
        hello ({NAME}) {
            return `Hello, ${NAME}!`;
        }
    }
    Scratch.extensions.register(new HelloBlocks());
})(Scratch);

This adds a Hello Blocks category with one round block, hello (world), that reports Hello, world!

Try it

  1. In the editor, click Add Extension (bottom-left), then Custom Extension.
  2. Choose Text, paste your code, and tick Run without sandbox if your extension needs the editor (see Sandboxed or not).
  3. Press Load. Your blocks appear in their own colour in the palette.

You can also load it from a file (Files tab) or a link (URL tab, or Mods → Add a custom extension).

The extension API

getInfo(): describes your extension

idRequired. Letters and numbers only, unique (e.g. gridsnap). Block opcodes become id_opcode inside projects, so don't change it later.
nameThe category name in the palette.
color1, color2, color3Block colour, its darker shade, and the border, as #rrggbb. Only color1 is needed; the others are worked out.
menuIconURIPicture for the category bubble (a data: URI or link).
blockIconURIPicture shown at the start of every block.
docsURIAdds a ? button to the palette that opens this link.
blocksThe list of blocks (below).
menusDrop-down menus your blocks use (below).

Blocks

opcodeRequired. The name of the method that runs, e.g. 'hello' runs hello(args, util).
blockTypeThe shape (next table).
textWhat the block says. [NAME] marks an input. Use an array of strings for C-blocks with more than one part.
argumentsOne entry per [INPUT]: {type, defaultValue, menu}.
isTerminaltrue = nothing can attach below (like stop all).
disableMonitortrue = reporters get no checkbox to show on stage.
hideFromPalettetrue = hidden from the palette (old blocks you still support).
filter[Scratch.TargetType.SPRITE] or [Scratch.TargetType.STAGE]: only show for sprites, or only for the Stage.
isEdgeActivatedHats only. true (default): the hat runs when your method changes from false to true. false: it runs every frame your method returns true.
branchCountC-blocks: how many slots for blocks inside (1 or more).
funcButtons only: the name of the method to run when clicked.

Block types: Scratch.BlockType.…

COMMANDA normal stack block, like move 10 steps.
REPORTERRound; gives back a value.
BOOLEANPointy; gives back true or false.
HATStarts a script when your method returns true (checked every frame).
EVENTA hat that only starts when your code says so (Scratch.vm.runtime.startHats(...)).
CONDITIONALA C-block like if: runs a slot when you call util.startBranch(1, false).
LOOPA C-block like repeat: util.startBranch(1, true) runs the slot and comes back.
BUTTONA button in the palette (like Make a Variable); runs func.
LABELA heading in the palette, not a block.
XMLRaw palette XML (advanced; use xml: '<sep gap="36"/>' for a gap).

Write '---' in the blocks list for a small gap between blocks.

Inputs: Scratch.ArgumentType.…

STRINGA text box.
NUMBERA round number box.
BOOLEANA pointy slot for true/false blocks.
COLORA colour picker; you get '#rrggbb'.
ANGLEA number with a direction dial.
MATRIXA 5×5 grid; you get a string of 25 0/1.
NOTEA piano keyboard; you get a MIDI note number.
COSTUME / SOUNDA menu of the sprite's costumes or sounds.
IMAGEA picture inside the block (use dataURI instead of defaultValue).

Menus

getInfo () {
    return {
        id: 'menudemo',
        name: 'Menu Demo',
        blocks: [{
            opcode: 'pick',
            blockType: Scratch.BlockType.REPORTER,
            text: 'size of [SIZE] in [SPRITE]',
            arguments: {
                SIZE: {type: Scratch.ArgumentType.STRING, menu: 'sizes', defaultValue: 'big'},
                SPRITE: {type: Scratch.ArgumentType.STRING, menu: 'sprites'}
            }
        }],
        menus: {
            // A fixed list. Items can be strings, or {text, value} when they should differ.
            sizes: {acceptReporters: true, items: ['small', 'big', {text: 'huge!', value: 'huge'}]},
            // A list worked out each time the menu opens: the name of a method.
            sprites: {acceptReporters: true, items: 'spriteNames'}
        }
    };
}
spriteNames () {
    const names = Scratch.vm.runtime.targets.filter(t => t.isOriginal && !t.isStage).map(t => t.getName());
    return names.length ? names : [''];
}

acceptReporters: true lets people drop a reporter into the menu. Without it, it's a fixed drop-down. A menu must never be an empty list.

Your block methods

Each block runs method(args, util):

argsThe inputs by name, e.g. {NAME: 'world'}. Values can be numbers or text whatever the type, so convert them with Scratch.Cast.
util.targetThe sprite running the block: util.target.x, .y, .setXY(x, y), .getName(), .lookupVariableByNameAndType(name, '')…
util.stackFrameAn object kept between runs of the same block in a loop (handy for counters).
util.startBranch(n, isLoop)C-blocks: run slot n; isLoop brings it back to your block afterwards.
return valueReporters and booleans give back this value. Return a Promise (or use async) and the script waits for it.

The Scratch object

Scratch.Cast.toNumber(x), toString, toBoolean, compare(a, b), toRgbColorList(x)Convert inputs the same way Scratch does.
Scratch.vmThe Scratch VM: Scratch.vm.runtime.targets, .startHats(...), .ioDevices… Unsandboxed only.
Scratch.rendererThe stage renderer (for drawing effects). Unsandboxed only.
await Scratch.fetch(url)Like fetch, but asks the person first if the site isn't trusted.
await Scratch.canFetch(url)Whether a request to that site is allowed.
await Scratch.openWindow(url) / Scratch.redirect(url)Open a new tab, or go to another page, after asking.
await Scratch.download(url, name)Save a file to the person's computer, after asking.
Scratch.translate('text')Marks text for translation (returns it unchanged if there's none).
Scratch.extensions.unsandboxedtrue when running unsandboxed. Check it first if you need Scratch.vm.

Sandboxed or not

Sandboxed (default)Runs in a separate, locked-down worker. It can only use its inputs and Scratch.Cast / Scratch.fetch; no Scratch.vm, no page, no sprites beyond its inputs. Safe for anyone to load.
UnsandboxedRuns in the editor itself with full access (Scratch.vm, util.target methods, the stage, the page). Needs Run without sandbox ticked, or people are asked when they load it from a link. Start the file with if (!Scratch.extensions.unsandboxed) throw new Error('This extension must run unsandboxed');

Extension examples

A hat that fires when something happens

(function (Scratch) {
    'use strict';
    if (!Scratch.extensions.unsandboxed) throw new Error('This extension must run unsandboxed');
    class Clock {
        getInfo () {
            return {
                id: 'clockhats',
                name: 'Clock',
                blocks: [
                    {opcode: 'whenMinute', blockType: Scratch.BlockType.EVENT, text: 'when the minute changes', isEdgeActivated: false},
                    {opcode: 'whenAfter', blockType: Scratch.BlockType.HAT, text: 'when it is after [HOUR] o\'clock',
                        arguments: {HOUR: {type: Scratch.ArgumentType.NUMBER, defaultValue: 17}}}
                ]
            };
        }
        // HAT: checked every frame; the script starts when this turns true.
        whenAfter ({HOUR}) { return new Date().getHours() >= Scratch.Cast.toNumber(HOUR); }
    }
    Scratch.extensions.register(new Clock());
    // EVENT: started by our own code.
    let last = new Date().getMinutes();
    setInterval(() => {
        if (new Date().getMinutes() !== last) {
            last = new Date().getMinutes();
            Scratch.vm.runtime.startHats('clockhats_whenMinute');
        }
    }, 1000);
})(Scratch);

A block that waits for the internet

(function (Scratch) {
    'use strict';
    class WebText {
        getInfo () {
            return {
                id: 'webtext',
                name: 'Web Text',
                blocks: [{opcode: 'get', blockType: Scratch.BlockType.REPORTER, text: 'text from [URL]',
                    arguments: {URL: {type: Scratch.ArgumentType.STRING, defaultValue: 'https://example.com'}}}]
            };
        }
        async get ({URL}) {
            try {
                const res = await Scratch.fetch(Scratch.Cast.toString(URL));
                return (await res.text()).slice(0, 10000);
            } catch (e) {
                return '';   // never throw: an error stops the script
            }
        }
    }
    Scratch.extensions.register(new WebText());
})(Scratch);

A C-block that repeats

// in blocks:
{opcode: 'twice', blockType: Scratch.BlockType.LOOP, text: 'do twice'}

// the method: util.stackFrame remembers the count between rounds
twice (args, util) {
    if (typeof util.stackFrame.loops === 'undefined') util.stackFrame.loops = 0;
    if (util.stackFrame.loops < 2) {
        util.stackFrame.loops++;
        util.startBranch(1, true);
    }
}

Blocks that move the sprite

// in blocks:
{opcode: 'jump', blockType: Scratch.BlockType.COMMAND, text: 'jump to the middle', filter: [Scratch.TargetType.SPRITE]}

// the method (unsandboxed): util.target is the sprite running it
jump (args, util) {
    util.target.setXY(0, 0);
}

Sharing your extension

Publish itIn fromturbo (website or app): Mods → 🧩 Publish an extension, pick your file. It shows up for everyone (see Share it with everyone).
A linkHost the .js file anywhere, then send fromturbo.pages.dev/editor.html?extension=YOUR_URL. It opens the editor with your extension loaded (people are asked first if it's unsandboxed).
In a projectProjects remember extensions loaded from a link and load them again when opened. Extensions pasted as text are saved inside the project.

Tips

  • Never change id or an opcode after people use your extension: their projects would lose those blocks.
  • Don't throw errors from a block; return a sensible value instead. An error stops the whole script.
  • Always convert inputs with Scratch.Cast. A NUMBER input can still get text dropped into it.
  • For the TurboWarp-compatible docs and many more examples, see docs.turbowarp.org.

Blocks from a mod

A mod can add blocks without a separate file, using the same format:

fromturbo.mods.register({
    id: 'my-blocks',
    name: 'My Blocks',
    run (api) {
        api.extensions.define(class {
            constructor (Scratch) { this.Scratch = Scratch; }
            getInfo () {
                return {
                    id: 'myblocks',
                    name: 'My Blocks',
                    blocks: [{
                        opcode: 'double',
                        blockType: this.Scratch.BlockType.REPORTER,
                        text: 'double [N]',
                        arguments: {N: {type: this.Scratch.ArgumentType.NUMBER, defaultValue: 4}}
                    }]
                };
            }
            double ({N}) { return Number(N) * 2; }
        });
    }
});

Blocks from define() only exist while the mod is installed. For blocks that should travel with a project, make an extension file instead.

Share it with everyone

In fromturbo (the website or the Mac app), open Mods and press 🍌 Upload a mod or 🧩 Publish an extension, then pick your .js file. It shows up for everyone in the Mods panel and in the extension library.

The first time, it asks you to sign in with Scratch (Scratch Auth). What you publish is credited to your Scratch username, never a real name.

Sections

The extension library has a filter button for each section, and every card has a small note saying which one it's in:

ScratchScratch's own extensions.
TurboWarpTurboWarp's extensions and its extension gallery.
fromturbo extensions ✓ / fromturbo mods ✓Approved by fromturbo, including the built-in mods.
Community extensions / Community modsPublished by anyone, not checked yet.

Mods need a fromturbo.mods.register({...}) call and extensions a Scratch.extensions.register(...) call. The name and description come from your code. Files can be up to 200 KB. Community items aren't checked by anyone, so only add ones you trust.

Turning off without a reload

When someone switches your mod off (or removes it), fromturbo undoes everything your mod added through api straight away: menu buttons, panels, api.on listeners, and the helpers below. No reload, and no clean-up code needed.

api.every(ms, fn)Like setInterval, stopped automatically.
api.after(ms, fn)Like setTimeout, cancelled automatically.
api.addStyle(css)Adds CSS to the page, removed automatically.
api.onCleanup(fn)Runs fn when the mod is switched off. Use it for anything you did outside api (your own setInterval, addEventListener, elements you added to the page).
run (api) {
    api.ui.addMenuButton('Time', () => api.ui.toast(new Date().toLocaleTimeString()));  // removed for you
    api.every(60000, () => console.log('another minute'));                               // stopped for you
    const onKey = e => console.log(e.key);
    window.addEventListener('keydown', onKey);
    api.onCleanup(() => window.removeEventListener('keydown', onKey));                     // yours to undo
}

Returning a function from run() still works too: it runs along with everything else. Blocks added with api.extensions.define() stay in the palette until the page is reloaded.

Built-in mods

Scratchity writes scripts for the selected sprite from a description. Scratch Colab lets a team edit one project live through a Firebase Realtime Database. Scratchpack opens and saves .scratchpack / .scratchplay archives. Embed gives you <iframe> code to put the project on any website, and custom extensions it uses run by themselves there (on the separate address embed.fromturbo.pages.dev, so they can't reach anyone's editor). All free, all switchable in Mods.
