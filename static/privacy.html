fromturbo Privacy Policy

Updated October 28, 2026

fromturbo runs in your browser. It has no accounts and does not sell or share your data. This page lists every place where something you do in fromturbo is sent somewhere else.

This website

fromturbo is hosted on Cloudflare Pages. Cloudflare handles the requests for the site and may keep standard logs such as IP addresses, as described in Cloudflare's privacy policy. fromturbo does not count your views or run analytics.

Scratchity

When you press Generate, the text you typed and the names of the selected sprite's variables, lists, broadcasts, costumes and sounds are sent to fromturbo's server and on to Cloudflare Workers AI to write the blocks. Nothing else from your project is sent. fromturbo does not store these requests.

Scratch Colab

Colab sends your whole project, your chosen display name and the room code to the Firebase Realtime Database you enter. That database belongs to whoever set it up, not to fromturbo, and anyone with the room code can see and change the project. Leaving a room removes your name from it.

Loading projects

When you load a project from another website, that website's privacy practices apply. For example, projects from Scratch fall under the Scratch privacy policy. Because Scratch does not let browsers download projects directly, the project ID is passed through a project-loading service run by the TurboWarp project, which may briefly log it for caching.

Cloud variables

Cloud variables connect to a cloud variable server run by the TurboWarp project, which may log the project ID and your username for up to 14 days. Data in cloud variables is public and is sent to everyone else using the project at the same time. A randomly generated username may be saved in your browser; you can change it in the editor.

Extensions

The extension gallery inside fromturbo is loaded from the TurboWarp project's extension gallery. Some extensions contact outside services to work; for example, translate and text-to-speech use the Scratch API. Gallery extensions ask for permission before reaching untrusted websites, though that can't be guaranteed to be perfect. Custom extensions you load from a URL or file ask before they load and can do more once you allow them.

Mods

Mods you install run inside the editor with full access to it and your project, and can contact any website. Only install mods from people you trust. Built-in mods are covered above.

Settings

Settings such as addon choices, your theme, installed mods and Colab details are stored only in your browser.

Questions

Open an issue at github.com/blockblock2/fromturbo.
